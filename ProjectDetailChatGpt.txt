### 2. PROFESSIONAL DESCRIPTION OF YOUR PROJECT [You can use this in your report / PPT]

*Azure Blob Storage Immutability for Audit Records*

In regulated industries like finance and healthcare, audit records must be preserved in their original state and protected from modification or deletion, even by an administrator. This is a compliance requirement for standards like SEC 17a-4, SOX, etc.

This project implements *WORM (Write Once, Read Many)* storage using *Azure Blob Storage Immutable Storage*.

We create an immutable storage layer where once a financial document (e.g., invoice, ledger, transaction log) is uploaded, it cannot be altered or deleted for 7 years.

*Key Technologies Used:*
- *Time-based Retention Policy:* Automatically protects the blob for a fixed duration (e.g., 7 years / 2555 days). Once Locked, this duration can ONLY be extended, never reduced. This is ideal for regulatory compliance.
- *Legal Hold:* An indefinite hold that protects blobs until the hold is explicitly cleared. Ideal for ongoing litigation or investigation.
- *Policy States:* Unlocked (for testing, can be modified) vs Locked (for production, irreversible).

*Use Cases Solved:*
1.  Making financial records unmodifiable for 7 years.
2.  Satisfying external auditors by proving data integrity.

*The Core Learning of this Project is Governance:* Understanding that a Locked policy is irreversible, so choosing between Legal Hold and Time-Based retention is a critical architectural decision that cannot be undone easily.
